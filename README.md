# 控制方向交互式学习树

当前版本：`ROADMAP TREE V1.0.5`

## 在线访问

[打开公开学习树](https://khananisur259-droid.github.io/control-learning-roadmap/)

## 离线使用

下载完整仓库后，双击根目录的 `index.html` 即可使用，不依赖网络或 CDN。

## 主要功能

- 176 个控制、机器人和具身智能知识节点；
- 分支展开与收起、全文搜索和知识范围筛选；
- 不绑定固定周数，只按前置关系给出学习顺序；
- 33 个关键节点提供 22 套带中文注释的可复制代码模板；
- 循迹框架支持任意合理数量的循迹传感器，八路仅作为项目实例和权重示例；
- 每套模板明确可复用部分、硬件适配项、原理说明和参考来源；
- 节点详情、学习验收要求和本地原始 Markdown 入口；
- 浏览器本地学习进度及 JSON 导入导出；
- 桌面端和手机端响应式布局。

本仓库只发布新人培养学习树，不包含比赛正式固件、控制参数、模型和其他项目资产。
